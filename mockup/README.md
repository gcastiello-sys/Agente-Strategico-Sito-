# Mockup landing (per GHL) — clienti Sistema Presenza Dominante

Mockup HTML statici, **uno per cliente**, ciascuno con le **3 versioni** di
posizionamento (A/B/C) come mini-landing complete. Servono da riferimento
visivo + sorgente copy da ricostruire su **GHL**.

## Come si usano
1. Apri il file `.html` del cliente nel browser per vedere le 3 versioni.
2. Scegli la versione (A/B/C).
3. Ricostruiscila su GHL copiando testi/struttura.
4. **Bottone quiz:** ogni CTA ha `href="INCOLLA_QUI_URL_QUIZ_GHL"` → sostituisci
   con l'URL del quiz GHL del cliente (i quiz sono già su GHL, vanno solo
   modificati per ognuno). Il quiz raccoglie il lead → GHL.

## Foto / immagini
I mockup usano **segnaposto** (riquadri tratteggiati con etichetta). Le foto vere
(team, immobili, recensioni, logo) si caricano **direttamente in GHL**. In
alternativa, rendi pubbliche le immagini su Drive e segnala i link per inserirle
nell'HTML.
